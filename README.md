# Duel Synth 
This is two synths in one system. It has functions that can be changed either manually by the user or randomly by pressing the randomiser button on each module. It can be used to create different sounds within both parts of the system, and has an additional 20 presets. In this version 1.0 the user is able to also see visually through the multiple spectroscopes, and can see the ADSR through there own scopes. I also fixed a bug with the second synth in version 1.1.
